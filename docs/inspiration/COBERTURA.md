# Cobertura e lacunas

Esta lista evita que captura de menu seja tratada como teste integral. O pedido de completude continua aberto enquanto houver lacunas acessíveis relevantes. O arquivo é um inventário rastreável para continuar a pesquisa antes do fim dos trials.

| Área | Cobertura atual | O que falta |
| --- | --- | --- |
| Pipedrive kanban | Quadro, cards, menus, filtro e pipeline | Drag com persistência, ganho/perda, falha e desfazer |
| Negócio | Seções, owner, followers, abas | Gravação e histórico de mudanças, casos longos/vazios |
| Produtos | Formulário e frequência | Fórmula salva, impostos/descontos/recorrência/parcelas |
| Atividade | Editor, tabela, calendário | Recorrência, convite, lembrete e sincronização |
| Contatos/campos | Tabela, colunas, tipos/regras | Operadores por tipo, importação, duplicidade e ações em massa |
| Leads | Estado vazio e adicionar | Conversão e automação |
| Intercom inbox | Lista/conversa/detalhes, menus e tabela | Envio, anexos, presença real, multisseleção, erros |
| Widget | Conteúdo, tema, posição, conversa e instalar | Instalação externa, usuário identificado, mobile real |
| Equipes | Entrada e bloqueio de plano | Formulário completo e permissões |
| Macros/atribuição | Editor existente, escopos e regras gerais | Ações completas e distribuição funcionando |
| Tickets/SLAs | Tipos existentes, atributos, estados internos/externos; SLA bloqueado | Criação, validações e aplicação dos SLAs |
| E-mail | Domínios, entrada, thread, assinatura/anexos/modelo | OAuth do provedor, entrega real e SMTP |
| Instagram/Facebook | Catálogo bloqueado no Intercom | Conexão e atendimento real |
| ManyChat múltiplos gatilhos | Dois no mesmo fluxo, catálogo e métricas por gatilho | Criação/gravação em fluxo descartável |
| Canvas | Publicado, inspetores, zoom, catálogo de nós | Drag, pan, conexão, multisseleção, atalhos e undo/redo exercitados |
| Condições/ações | Categorias, campos, exemplos publicados | Todos operadores, randomizador, IA, erros de validação |
| Integrações de automação | HTTP, Sheets, Meta, Hotmart anunciados | Configuração completa sem dados de terceiros |
| Sequências/regras | Listagens e automações básicas | Editor próprio e regras completas |
| Responsividade | Pipedrive e Intercom emulação; ManyChat desktop estreito | ManyChat mobile, widget instalado e teclados móveis |
| Visual pixel a pixel | Prints e amostras CSS | Geometria fina, ícones, hover/foco/disabled/erro por componente |
| Módulos adicionais | Fontes de conhecimento, catálogo de 27 relatórios, outbound inicial | Editores detalhados, execução, integrações e configurações remanescentes |
| ActiveCampaign | Adiado explicitamente | Login e pesquisa posterior |

Não faltam somente prints: alguns itens exigem conta conectada, plano superior ou ambiente descartável. A coleta de menus e detalhes somente leitura pode continuar; não testar publicação ou integração ativa em automação operacional de terceiro.
